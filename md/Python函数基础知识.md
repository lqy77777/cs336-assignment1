## 先区分：函数与方法

- `open()` 是 Python 内置函数，可以直接调用。
- `f.read()` 是文件对象的方法，要通过文件对象 `f` 调用。
- `text.find()` 是字符串对象的方法，要通过字符串对象 `text` 调用；`bytes` 对象也有 `find()` 方法。

本文的 `read()` 指文件对象的读取方法，`find()` 主要指字符串的查找方法。

“返回值”是调用完成后交给调用者的结果，可以用变量接收。返回值不等于屏幕输出，显示结果通常需要调用 `print()`。

## 1. open()：打开文件

### 作用与常用写法

打开文件并返回一个文件对象，后续通过这个对象读取或写入内容。

```python
open(file, mode="r", encoding=None)
```

上面只列出常用参数，并非完整签名。

### 参数与返回值

| 参数 | 含义 | 示例 |
| --- | --- | --- |
| `file` | 文件路径，可以是相对路径或绝对路径 | `"data.txt"`、`"data/train.txt"` |
| `mode` | 打开模式，默认是 `"r"`，即以文本方式只读 | `"r"`、`"w"`、`"a"`、`"rb"` |
| `encoding` | 文本模式下，指定字节与字符串之间转换所用的编码 | `"utf-8"` |

**返回值：** 文件对象，不是文件内容。通常用 `f` 接收，再调用 `f.read()` 等方法。

### 常见打开模式

| 模式 | 含义 | 文件不存在时 | 文件已存在时 |
| --- | --- | --- | --- |
| `"r"` | 读取文本 | 抛出 `FileNotFoundError` | 保留内容 |
| `"w"` | 写入文本 | 创建文件 | **打开时立即清空内容** |
| `"a"` | 在文件末尾追加文本 | 创建文件 | 保留内容，写入时追加 |
| `"rb"` | 读取二进制数据 | 抛出 `FileNotFoundError` | 保留内容 |
| `"wb"` | 写入二进制数据 | 创建文件 | **打开时立即清空内容** |

补充：`t` 表示文本模式，默认省略；`b` 表示二进制模式；`+` 表示同时允许读写，例如 `"r+"`。创建文件不会自动创建缺失的父目录。

### 示例：打开并读取文本文件

假设当前工作目录下已有 UTF-8 编码的 `data.txt` 文件。

**先理解参数、变量和返回值：**

- `"data.txt"`：要打开的文件路径。
- `"r"`：以只读文本模式打开。
- `encoding="utf-8"`：使用 UTF-8 解码文件内容。
- `f`：进入 `with` 代码块时获得的文件对象。
- `content`：接收 `f.read()` 返回的字符串。
- `print()`：显示字符串，本身的返回值是 `None`。

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```

**逐行解释：**

1. `with open(...) as f:`：打开文件，将文件对象交给 `f`，进入缩进代码块。
2. `content = f.read()`：读取文件内容，并保存到 `content`。
3. `print(content)`：离开代码块后输出内容。此时文件已经自动关闭，但读取出的字符串仍然可用。

### 注意事项

- 推荐使用 `with`：离开代码块时会自动关闭文件，代码块中发生异常时也会进行关闭处理。
- 相对路径相对于程序的**当前工作目录**，不一定相对于 `.py` 文件所在目录。
- 文本模式建议明确指定与文件一致的编码；省略 `encoding` 时，不要假设默认一定是 UTF-8。
- 二进制模式不要传 `encoding`，例如 `open("data.bin", "rb")`。
- `open()` 本身不返回文件内容，读取内容还需要调用 `read()` 等方法。

## 2. read()：读取文件内容

### 作用与常用写法

从文件的**当前位置**开始读取内容。

```python
f.read(size=-1)
```

### 参数与返回值

| 参数或对象 | 含义 |
| --- | --- |
| `f` | 已打开且允许读取的文件对象 |
| `size` | 最多读取的数量；省略或传负数时，读取从当前位置到文件末尾的全部内容 |

`size` 的单位取决于打开模式：

- 文本模式：字符数。
- 二进制模式：字节数。

**返回值：**

- 文本模式返回 `str`，例如 `"hello"`。
- 二进制模式返回 `bytes`，例如 `b"hello"`。
- 对普通文件，在文件末尾继续读取会返回空字符串 `""` 或空字节串 `b""`。
- `read(0)` 也返回空内容，但不会前进，因此不能仅凭这次结果判断是否到达末尾。

### 示例：连续读取

假设 `data.txt` 的内容恰好是 `abcdef`，末尾没有换行。

**先理解参数、变量和返回值：**

- `f`：以文本模式打开的文件对象。
- `2`：每次最多读取两个字符。
- `first`、`second`：分别保存前两次读取的字符串。
- `rest`：保存从当前位置到末尾的剩余字符串。
- `end`：保存到达末尾后再次读取的结果，即 `""`。

```python
with open("data.txt", "r", encoding="utf-8") as f:
    first = f.read(2)
    second = f.read(2)
    rest = f.read()
    end = f.read()
```

**逐行解释：**

1. 打开文件，读取位置位于文件开头。
2. `first = f.read(2)`：得到 `"ab"`，读取位置移到 `b` 后面。
3. `second = f.read(2)`：从当前位置继续读，得到 `"cd"`。
4. `rest = f.read()`：读取剩余内容，得到 `"ef"`。
5. `end = f.read()`：已经到达末尾，得到 `""`。

关键理解：连续调用 `read()` 会继续往后读，**不会每次都从头开始**。

### 文本读取与二进制读取

对于没有换行、内容为 `你好` 的 UTF-8 文件：

| 调用方式 | 返回值 | 含义 |
| --- | --- | --- |
| 文本模式下 `f.read(1)` | `"你"` | 读取一个字符 |
| 二进制模式下 `f.read(1)` | `b"\xe4"` | 读取一个字节，不足以表示完整的“你” |

UTF-8 中一个字符可能占多个字节，所以“读取一个字符”和“读取一个字节”并不相同。

### 注意事项

- `read()` 不会自动删除换行符，读取结果可能包含 `\n`。
- 文本模式默认会进行换行转换，例如将文件中的 `\r\n` 转换为 `\n`；二进制模式读取原始字节。
- 对大文件直接调用 `read()` 可能占用大量内存，可以考虑分块读取或逐行遍历。
- 对可定位的普通文件，可以先调用 `f.seek(0)` 将位置移回开头，再重新读取；`seek()` 本身不是读取操作。
- `read()` 读取内容，`readline()` 读取一行，`readlines()` 返回由各行组成的列表。

## 3. find()：查找子串

### 作用与常用写法

在字符串中查找指定子串第一次出现的位置。

```python
text.find(sub, start, end)
```

`start` 和 `end` 可以省略，最常见的调用是 `text.find(sub)`。这些参数按位置传入。

### 参数与返回值

| 参数或对象 | 含义 |
| --- | --- |
| `text` | 被查找的原字符串 |
| `sub` | 要查找的子串，必须是字符串 |
| `start` | 搜索起点，包含该位置；默认从头开始 |
| `end` | 搜索终点，不包含该位置；默认搜索到末尾 |

**返回值：** 整数 `int`。

- 找到时，返回子串在**原字符串中**首次匹配的起始索引，索引从 `0` 开始。
- 找不到时，返回 `-1`。
- 指定搜索范围后，返回的仍然是原字符串的索引，而不是相对于 `start` 的偏移量。

### 示例：首次匹配与搜索范围

**先理解参数、变量和返回值：**

- `text`：被搜索的字符串 `"banana"`。
- `"ana"`：要查找的子串。
- `first`：从头搜索的返回值。
- `next_match`：从索引 `2` 开始搜索的返回值。
- `missing`：查找不存在的子串时的返回值。
- `bounded`：仅在索引区间 `[0, 3)` 中查找的返回值。

```python
text = "banana"
first = text.find("ana")
next_match = text.find("ana", 2)
missing = text.find("xyz")
bounded = text.find("ana", 0, 3)
```

索引对应关系：

```text
字符： b  a  n  a  n  a
索引： 0  1  2  3  4  5
```

**逐行解释：**

1. `text = "banana"`：创建要搜索的字符串。
2. `first = text.find("ana")`：第一次匹配从索引 `1` 开始，返回 `1`。
3. `next_match = text.find("ana", 2)`：从索引 `2` 开始搜索，在索引 `3` 找到匹配，返回 `3`。
4. `missing = text.find("xyz")`：找不到，返回 `-1`。
5. `bounded = text.find("ana", 0, 3)`：搜索范围对应 `"ban"`，范围内没有完整的 `"ana"`，返回 `-1`。

### 常见错误：直接将 find() 的结果作为条件

不建议写 `if text.find("ana"):` 来判断是否找到，因为：

- 找到且索引为 `0` 时，`bool(0)` 是 `False`。
- 没找到时返回 `-1`，但 `bool(-1)` 是 `True`。

如果需要位置，先保存索引，再与 `-1` 比较。

**变量与返回值：** `text` 为原字符串，`index` 保存 `find()` 返回的整数，`index != -1` 得到布尔值，表示是否找到。

```python
text = "banana"
index = text.find("ana")
if index != -1:
    print("找到了，位置是：", index)
```

**逐行解释：**

1. 创建字符串 `text`。
2. 查找 `"ana"`，把返回的索引 `1` 保存到 `index`。
3. 判断 `index` 是否不等于 `-1`。
4. 条件成立时输出匹配位置。

如果只想判断是否包含，不需要具体位置，直接使用 `"ana" in text`，返回 `True` 或 `False`。

### 注意事项

- `find()` 区分大小写，例如 `"Python".find("python")` 返回 `-1`。
- `find()` 只返回第一次匹配的位置，不会返回所有匹配位置。
- 字符串索引按字符计算，不是 UTF-8 字节偏移。
- `find()` 不会修改原字符串。
- `index()` 与 `find()` 类似，但找不到时会抛出 `ValueError`。
- `rfind()` 返回搜索范围内最后一次匹配的位置。
- `bytes` 也支持查找，例如 `b"banana".find(b"ana")` 返回 `1`，这里的索引按字节计算。

## 4. 组合示例

任务：打开一个文本文件，读取内容，查找 `"hello"` 第一次出现的位置。

**先理解参数、变量和返回值：**

- `"data.txt"`：已有的 UTF-8 文本文件路径。
- `f`：`open()` 打开的文件对象。
- `content`：`read()` 返回的完整文本字符串。
- `position`：`find()` 返回的整数索引；找不到时为 `-1`。

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

position = content.find("hello")

if position != -1:
    print("第一次出现的位置：", position)
else:
    print("没有找到")
```

**逐行解释：**

1. `with open(...) as f:`：打开文件，进入代码块。
2. `content = f.read()`：读取文件的全部文本内容。
3. `position = content.find("hello")`：文件已自动关闭，在保存的字符串中查找 `"hello"`。
4. `if position != -1:`：判断是否找到。
5. 找到时输出第一次出现的索引。
6. `else:`：处理没有找到的情况。
7. 输出“没有找到”。

三者的关系：**`open()` 得到文件对象 → `read()` 得到内容 → `find()` 得到匹配位置。**

## 5. 对比与自测

### 快速对比

| 调用 | 作用 | 返回值 | 关键注意点 |
| --- | --- | --- | --- |
| `open(...)` | 打开文件 | 文件对象 | 注意模式、编码和关闭文件 |
| `f.read(...)` | 读取内容 | `str` 或 `bytes` | 从当前位置继续读取 |
| `text.find(...)` | 查找子串 | 整数索引或 `-1` | 索引从 `0` 开始，不能直接用返回值判断是否找到 |

### 自测题

1. 为什么 `f = open("data.txt")` 后，`f` 不是字符串？
2. 文件内容为 `abcdef`，连续两次调用 `f.read(3)`，分别得到什么？
3. `"hello".find("he")` 和 `"hello".find("xyz")` 分别返回什么？
4. 为什么 `if text.find("hello"):` 不能正确判断是否找到？
5. 只想判断是否包含某个子串，应该优先使用什么写法？

<details>
<summary>参考答案</summary>

1. `open()` 返回文件对象，调用它的 `read()` 方法后才得到内容。
2. 在刚打开的文本文件上依次得到 `"abc"` 和 `"def"`，因为读取位置会前进。
3. 分别返回 `0` 和 `-1`。
4. `0` 表示在开头找到，但作为条件为假；`-1` 表示没找到，但作为条件为真。
5. 使用 `sub in text`，例如 `"hello" in text`。
